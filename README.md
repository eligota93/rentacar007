# Rent A Car 007 — Website

## Hapja lokale
Hapni `index.html` në shfletues ose publikoni të gjithë dosjen në Vercel, Netlify, GitHub Pages ose hostin tuaj.

## Ndryshimi i të dhënave të veturave
Të dhënat kryesore janë në listën `vehicles` brenda:
- `script.js` — kartat e ballinës
- `detail.js` — faqet e detajeve

Zëvendësoni `Shto vitin`, `Shto transmisionin`, `Shto karburantin`, `Shto numrin` dhe çmimin me të dhënat reale.

## Fotografitë
Zëvendësoni skedarët në `assets/images/` me fotografitë reale të pesë veturave duke ruajtur emrat e skedarëve, ose ndryshoni shtigjet në `script.js` dhe `detail.js`.
